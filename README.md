# Silent Protocol organisation profile

`profile/README.md` is shown on https://github.com/Silent-Protocol-Inc.

Brand: "Night Watch", the identity of silentprotocol.top. Warm graphite ground `#0e0c0a`, one sodium accent
`#ff8f4a` with lamp `#ffc27a`, cream text `#f3ece2`; Bricolage Grotesque (display), Geist (text), JetBrains Mono (labels).
The mark is a pentagon watch with a sodium diamond inside a dotted ring (`assets/src/mark.svg`).

| File | Use |
| --- | --- |
| `assets/banner.png` (1680×480) | Profile banner |
| `assets/avatar.png` (1000×1000) | Organisation avatar (upload in organisation settings) |
| `assets/src/` | HTML and SVG sources |

Re-render after editing a source (needs Playwright and Chromium):

```sh
node assets/src/render.mjs /path/to/node_modules/playwright/index.mjs
```
